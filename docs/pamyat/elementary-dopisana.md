29 августа 2026 ступень Elementary дописана целиком: **тридцать один модуль из
тридцати одного**. За сессию сделаны модули 26–31, каждый прошёл круг «скрипты
→ методист и редактор → правки → озвучка». Около ста тридцати находок на шесть
модулей.

**На боевом сайте двадцать один модуль.** О выкладке 22–31 владелец не просил —
не выкладывать без явной просьбы.

**Следующая работа — общий проход по всей ступени** (решение владельца от 20
августа): круг проверки на модуль был один, мелкое копилось. Что в него брать —
в конце `docs/zapiska-elementary-dopisana.md`: 86 мёртвых карточек по курсу,
`the` без объяснения 2623 раза, рамка «Соедини две строки» в девяти модулях,
запятая перед `because`, значения карточек.

**Why:** без этого следующая сессия начнёт писать модуль 32, которого в
программе нет, или полезет выкладывать без просьбы.

**How to apply:** начинать с записки, а не с программы. Открытые вопросы
владельцу — там же, раздел 5.
