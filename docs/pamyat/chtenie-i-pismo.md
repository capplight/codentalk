**Выложено 19 августа 2026.** Ступень Beginner: 258 уроков, 55,8 часа, чтение
в каждом модуле, письмо в шести.

## Чтение

Прежде текста для чтения не было в модулях 1, 2, 4, 5, 6 — вся первая половина
первой части. Теперь есть везде, и жанры разные: список и бланк (1), переписка
(2), разговор из вопросов (4), объявление с припиской (5), опись комнаты (6).

## Письмо

Вид задания `essay` до этого дня не использовался в курсе английского ни разу.
Теперь шесть уроков — **там, где источник называет жанр**, а не в каждом модуле:

| Модуль | Что пишут | Опора, CEFR Companion 2020 |
| --- | --- | --- |
| 3 | рассказ о себе | с. 66, Overall written production |
| 10 | сообщение о встрече | с. 83, Correspondence |
| 11 | объявление о продаже | с. 67, Creative writing |
| 13 | объявление о сдаче | с. 67, Creative writing |
| 21 | сообщение о вкусах | с. 83, Correspondence |
| 25 | открытка | с. 83, Correspondence |

**Эссе на этой ступени нет и быть не может:** с. 68, шкала Reports and essays,
графы A1 и Pre-A1 — «No descriptors available». Первые описания с A2. Это
основание всех шести уроков; если кто-то предложит «эссе для Beginner», ответ
здесь.

**Итоги уроков письма названы по проверяемой половине** («находить», «проверять»),
потому что письмо машина не оценивает, а проверка требует, чтобы каждый итог
спрашивался работой.

## Чему научила приёмка — три круга, 32 находки

1. **Номер страницы берётся только `npm run pdf --find`.** Вывод из разметки
   текстового разбора дважды разошёлся с настоящим на единицу.
2. **Раздел «вопросы» в `npm run kontrol` надо читать.** Я весь день смотрел
   только счёт ошибок и пропустил пять находок, включая два перепутанных разбора.
3. **Правка переносит утечку, если её не проверить.** Дважды убирал совпадение
   врезки с заданием — и сажал его на другой вариант.
4. **Правка доходит до врезки и не доходит до подсказок.** «But соединяет два
   прилагательных» осталось в двух подсказках после исправления во врезке.
5. **Образец обязан проходить собственный список самопроверки.**
6. **Порог `minWords` берётся по самому короткому верному ответу**, а не по
   образцу: прежний упрекал за верное.
7. **Утверждения о том, как люди читают, возвращаются.** Снял одно — появились
   четыре. Источники таких сведений не дают вовсе.
