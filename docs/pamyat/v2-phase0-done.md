Август 2026, автономная работа по заданию владельца. Порядок работ — в [[v2-work-order]], техзадание — [[platform-v2-spec-location]].

**Ветка `v2` в `github.com/capplight/codentalk`. `main` с работающей первой версией не тронут.**

**База данных: Neon, Frankfurt (eu-central-1), Postgres 18.** Две строки подключения: `DATABASE_URL` через пул для сайта, `DIRECT_URL` напрямую для миграций (через пул миграции ломаются). Обе в `.env.local`. Локальная база — `docker compose up -d`, тоже Postgres 18 для совпадения версий.

**Готово и проверено сквозным прогоном на настоящей базе** (`npm run smoke`, сервер на 3010, нужен `RATE_LIMIT_DISABLED=1`):
- вход и регистрация: Argon2id, ответ не различает «нет такой почты» и «неверный пароль»;
- перенос материалов из `content/` в базу (`npm run db:seed`): 4 направления, 6 курсов, 34 модуля, 101 урок. **Скрипт падает, если урок с чужими успехами исчез из репозитория** — защита испытана подставным уроком, а не только написана;
- программный интерфейс `/api/v1/*`: каталог, курс, взятие курса, мои курсы, личный кабинет, сохранение места в уроке, проверочные работы, сертификаты, подписка;
- сертификаты: выдача с проверкой права, публичная проверка без входа, номер не по порядку и без похожих знаков (0/O/1/I/L), выдача освобождает место из двух;
- заглушка платёжной системы за интерфейсом `BillingProvider`, включение подписки заглушкой запрещено на рабочем сайте.

**53 теста правил в `lib/domain/`** (enrollment, progress, testing, certificate) — без базы и React, запуск `npm test`.

**Решения, принятые самостоятельно (владелец разрешил решать самому):**
- Ограничение частоты — счётчики в памяти процесса. Хватает против перебора паролей, при росте нагрузки переносить в общее хранилище; наружу смотрит одна функция, менять только `lib/api/rate-limit.ts`.
- **Регистрация: 20 в час с адреса, а не 5 за 15 минут.** Владелец преподаватель, целый класс из одного учебного заведения выходит с общего адреса — строгий предел закрыл бы доступ всей группе.
- Отключение ограничений для проверок защищено дважды: переменная `RATE_LIMIT_DISABLED=1` И `VERCEL_ENV !== "production"`. По `NODE_ENV` проверять нельзя — собранный сайт запускается с production и локально.
- Главы первой версии разложены по модулям через юниты (`questSlug`, `textSlug`, `exerciseSlugs`); главы без юнита кладутся в курс без модуля (`moduleId` необязателен).

**Чего ещё НЕТ:**
- PDF сертификатов. Нужен встроенный шрифт с кириллицей (стандартные шрифты PDF только латиница) — это бинарный файл в репозиторий, отложено.
- Внешний вид страниц кроме входа и регистрации — дизайн не решён владельцем.
- Наполнение проверочных работ: таблицы `tests`/`test_questions` есть, вопросов нет — это работа по контенту, требует владельца.
- Сквозной прогон не покрывает платный курс: опубликованных платных курсов пока нет (английский бесплатный, остальные направления — анонсы). Правила покрыты тестами.

**Ловушка окружения, уже стоившая времени:** Prisma генерирует клиент в `lib/db/generated/` (не в `node_modules`), и после правки схемы проверка типов ругается, пока не выполнить `npx prisma generate`.
