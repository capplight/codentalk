Общий проход по ступени Elementary закончен **30 августа 2026**. Замысел был
принят владельцем 20 августа: круг на модуль сейчас, общий проход по всей
ступени — когда она дописана.

**Устройство.** Тридцать один модуль одним заходом не берётся. Ступень
разделена на четыре части (1–7, 8–13, 14–21, 22–31), на каждую позван методист
и редактор — восемь проходов. **Запускать всех восьмерых разом нельзя:** первая
попытка убила всех до единого на лимите сессии, ни один разбор не дошёл. Дальше
шли парами и по одному, и это сработало.

**Итог: 66 находок методистов, 7 редакторов, все внесены; ступень выложена на
сайт вместе с переносом банка вопросов в базу.**

**Главное, чего круг НЕ дал.** Понятность ловится хуже всего: для ступени и
источников есть файлы, с которыми сверяют, а для понятности сверять не с чем,
кроме человека, который не понял. Самую понятностную находку прохода сделал
владелец, а не проверяющие.

**Открытый вопрос владельцу — модель редактора.** 13 августа он переведён с
opus на sonnet ради экономии; основание было «механику забрал `npm run yazyk`,
осталась понятность». Счёт прохода это основание не подтверждает. Проверить
дёшево: пустить редактора на opus по модулям 16–21, которые он на sonnet
объявил чистыми.
