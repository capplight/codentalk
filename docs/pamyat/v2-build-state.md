Состояние на 16 августа 2026. Всё в `main`, репозиторий
`github.com/capplight/codentalk` — **ОТКРЫТ ВСЕМ**, см. [[bezopasnost-i-vhod]].

## Страницы

- `/` — витрина. Заголовок «Учись понимать, а не зазубривать». Карточка
  направления «Английский» и отдельная карточка курса по коду. Кнопка ведёт
  гостя на вход, вошедшего — в его кабинет.
- `/napravlenie/english` — ступени сеткой: Beginner (до A1, открыта),
  Elementary и Pre-Intermediate («готовится»). Печать «Пройдено» по сданному
  экзамену. Названия ступеней НЕ переводятся и переводом не поясняются.
- `/learn/[course]` — состав ступени, открыт всем.
- `/learn/[course]/[lesson]`, `/proverochnaya/[module]`, `/ekzamen` — **закрыты
  до входа**, возврат через `?dalshe=`.
- `/dashboard`, `/login`, `/register`, `/zabyl-parol`, `/novyy-parol`.
- `/certificate/[serial]` — проверка, `/certificate/[serial]/blank` — бланк для
  печати, `/proverka` — проверка по номеру.

## Сертификат

Выдаётся, когда пройдена вся ступень: все уроки, все работы модулей, экзамен.
Бланк печатается браузером («Сохранить как PDF»), своей выделки PDF нет
намеренно. На бланке: курс, ступень, часы, балл, имя, номер. Прошедшее время
держится за курс — пола ученика платформа не знает.

**`npm run obrazec`** выдаёт образец учебному аккаунту, чтобы видеть документ
при правках оформления. **Убирать за собой обязательно:**
`npm run obrazec -- --clean`.

## Пороги и охват работ

Порог везде **80%** (8 из 10 в работе модуля, 24 из 30 на экзамене), в
интерфейсе показывается счётом, а не баллами. У вопроса экзамена есть признак
модуля: выборка берёт по вопросу из каждого, ни один не пропускается. До этого
пропускала в среднем четыре модуля из двадцати пяти.

## Оформление

Светлая тема по умолчанию, за настройкой системы не следуем. Шкала кеглей
`--step--1`…`--step-4`, размеры только из неё. Обложки карточек: у языков флаг
во всю ширину (растягивается), у курсов по коду знак на цветном поле (не
растягивается, стоит по центру). Высота обложек задана прямо — 128 точек у
больших карточек, 76 у готовящихся.

## Как посмотреть

```
npm run build && npx next start -p 3010
```

Учебные аккаунты — `npm run demo`. Пароль в репозитории больше не лежит:
берётся из `DEMO_PASSWORD` или придумывается случайно и печатается один раз.
Скрипт отказывается работать против рабочей базы без явного согласия.

## Чего нет

- Проверочные работы частей написаны как данные, но ученику недоступны:
  страницы для них нет, перенос в базу их не кладёт.
- Говорения нет: 198 заготовок записей ждут решения владельца (п. 1.4).
- Оплаты нет вовсе, и разговора о ней в текстах тоже — решение владельца.
