23 августа выкладка упала с первой попытки: `npm run build` вернул ошибку типа в
`courses/resheno.ts` — я записал разбор случая на себя, `kto: "автор"`, а тип
поля пускает только владельца, методиста и редактора.

**Why:** `check:content`, `kontrol` и `yazyk` запускаются через **tsx** и на типы
не смотрят вовсе. Все три давали ноль ошибок, а сборка на Vercel падала. Один
прогон сборки потрачен впустую.

**How to apply:** порядок перед выкладкой — скрипты → **`npm run build`** →
`npx vercel --prod --token "$VT"` → `npm run db:seed:courses` → проверка запросом
(307 = выложено за замком, 404 = не доехало).

И отдельно: тип поля `kto` пускает только проверяющих — это не случайность, а
правило проекта, записанное в коде: **автор не принимает свою работу**.
Связано с [[vercel-deploy]].
