**31 августа 2026 ступень Beginner переведена целиком** — 573 строки примеров
из 573. Круг закрыт 1 сентября: четыре прохода (методист 1–3, редактор 1–14,
методист 4–14, редактор 15–25), около ста находок, все внесены.

**Главное для следующей сессии: объяснения переделывать НЕ пришлось.** Beginner
уже написан по методу, ради которого переделывалась Elementary: начинает с
русской фразы («Ты рассказываешь о друге: „Алим работает в магазине. Я знаю
Алима"»), называет расхождение с русским («В русском окончание меняется у
каждого лица, в английском — у одного»), ссылается на соседние модули — 93
ссылки против 36 у переделанной Elementary.

Диагноз владельца («объяснения слабые, переведены с английского») относился к
Elementary, а не ко всему курсу.

| | Было | Стало |
|---|---|---|
| строк с переводом | 0 из 573 | 573 |
| модулей без единой ссылки | 2 | 0 |
| одна строка с двумя переводами | 5 | 0 |

**Что нашли проверяющие:** два выдуманных запрета (оба опровергнуты собственным
курсом — «`am` только после I» ломается девять раз в модуле 4); обращение «ты»,
не доехавшее до трёх модулей; `teacher` в трёх русских одеждах; **39 вопросов
работ, повторяющих задания уроков** на три модуля — переписано десять.
