Август 2026: владелец задумал развитие [[codentalk-project]] из бесплатной платформы квестов в **подписочную ed-tech платформу с регистрацией**. Обсуждено в режиме «я CTO с опытом 10+ лет», разработка ещё НЕ начата — сначала архитектура и ТЗ.

**Каталог (планируемый):**
- Языки приоритетные: английский, французский, испанский, арабский. Менее приоритетные: итальянский, китайский, японский, немецкий, корейский, турецкий.
- Программирование: введение в веб (HTML/CSS) — бесплатно; далее JavaScript, TypeScript, React, Angular, Vue, Next.js, Python, C#, C++.
- Готовые профессии: project management, QA, Power BI, машинное обучение, интеграция ИИ, дата-аналитика.
- Отдельный таб — чат с ИИ для практики во время обучения.

**Монетизация — freemium с ОДНОЙ подпиской на всё:**
- Бесплатно: английский + введение в программирование (HTML/CSS).
- Платно по единой подписке: все остальные языки, программирование и профессии. Не поурочная покупка.
- Ограничение доступа: **не больше 2 курсов одновременно**. Выбран **вариант A — «активно в этом месяце»** (открыл курс хотя бы раз = он занимает слот весь месяц). Выбран за простоту реализации в MVP; отвергнуты вариант B (сброс по 3 дням неактивности) и C (слот освобождается после домашки) как слишком сложные.

**Конкурентное преимущество (формулировка владельца, важно для приоритизации):** Coursera/Udemy продают дорогой курс от преподавателя с видеоуроками — человек платит, чувствует вину, не учится. Здесь: самостоятельное обучение по материалам, дешёвая ежемесячная подписка, можно отписаться и вернуться когда захочешь. Результат зависит от самого ученика. По сути «Netflix для образования».
**Главный риск этой модели, признанный обеими сторонами:** люди подпишутся, ничего не сделают, отпишутся. Нужен механизм «зацепить в первые 7 дней» — пока не спроектирован, но обязателен к проработке.

**Аудитория:** не только школьники, но и взрослые, которые ищут себя в карьере (смена профессии).

**Условия работы:** личный проект владельца, спешки нет, времени много. Команда — только владелец (роль CTO) и Claude; код пишут агенты, которых планируется распределить по ролям (CTO руководит, software architect планирует, дизайнер — фронт, бэкенд-агент — сервер и интеграции, QA тестирует, PM координирует и общается с владельцем). Владелец согласился с замечанием, что агенты без координатора = хаос, поэтому PM — единая точка ответственности.

**Порядок платформ:** сначала веб-сайт, позже перенос в мобильное приложение — почву готовить заранее в архитектуре. Владелец отверг подход mobile-first («для мобилки запуститься тяжелее, в сайт залить легче»), несмотря на довод про ~70% мобильных пользователей в ed-tech.

Решения по объёму MVP — в [[platform-v2-mvp-scope]].
