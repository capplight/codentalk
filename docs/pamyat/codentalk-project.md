CodeNTalk (e:\My Project\codentalk.kz) — бесплатная платформа изучения языков (позже — программирования) через истории-квесты. Начат в июле 2026.

**Владелец**: бывший преподаватель офлайн-школы (английский, другие языки, программирование), Instagram @codentalk.kz, ранее разрабатывал приложение для языковой практики через голосовой ИИ. Цель — давать знания бесплатно. Общение на русском.

**Принципы продукта** (важно при добавлении фич): без стриков/сердечек/штрафов («не как Дуолинго, попроще»), сюжет вместо карточек, ошибка → мягкая подсказка и повтор, награда — «разговорник» собранных фраз.

**Структура каталога** (июль 2026): Направление (Track: english, python) → уровень (Course) → 4 РАЗДЕЛА уровня: Квесты (/quests, section не задан: сюжет+экзамен), Правила (/rules — RulesSet в content/<level>/rules.ts, рендерер components/RulesView.tsx: TOC, таблицы, примеры с озвучкой, типичные ошибки), Тексты (/texts, section:"text" — сюжетные практики + 20 адаптаций классики из public domain: Эзоп ×10 (лев/мышь, заяц/черепаха, ветер/солнце, муравей/голубка, две мыши, ворона, лиса/виноград, собака/кость, волк, гусыня, молочница, отец/сыновья), Уайльд, О. Генри («Дары волхвов», «Последний лист», «Полицейский и гимн»), Толстой «Три вопроса», Чехов «Пари», Конан Дойл, Джером К. Джером «Трое в лодке»; формат: reading с вопросами + listening-мораль + задание на закрепление). Упражнения: по 2 тренажёра на уровень (drills.ts + drills-2.ts), Упражнения (/exercises, section:"exercise" — drills.ts тренажёры). /course/[course] = хаб с 4 карточками. getChapter section-aware: next внутри раздела, nextCourse только из квестов. ChapterList принимает courseSlug+chapters (не весь course — не сериализовать лишнее!). Главная `/` = карточки направлений (English играбелен, Python — comingSoon с силлабусом). `/track/[track]` = уровни направления с картой Starter→B2. `/course/[course]` = главы уровня (хлебная крошка ведёт на track). Хелперы в content/index.ts: tracks, englishLevels, courses (flatMap уровней), getTrack, getCourse, getTrackOfCourse, getChapter (nextCourse ищет следующий уровень внутри того же track).

**Стек**: Next.js 15 App Router + TypeScript, без Tailwind (CSS-токены «тревел-дневник» в app/globals.css + CSS modules). Контент = данные в content/ (главы добавляются без кода, разметка {word|перевод} для тап-перевода). Прогресс в localStorage (lib/progress.ts), озвучка через Web Speech API (lib/speech.ts). Supabase отложен до появления аккаунтов.

**Этап 2 — Writing и Speaking (готово, июль 2026)**: завершают 4-навыковую (reading/listening/writing/speaking) IELTS-подобную структуру.
- **Writing**: новый тип контента `WritingPrompt {slug, title, instruction, hint, minWords, sample, checklist[]}` в `lib/types.ts`, `Course.writing?: WritingPrompt[]`. По 3 промпта на уровень (15 всего) в `content/english-{level}/writing.ts`, привязаны к грамматической теме уровня (Starter: to be/have/articles; A1: Present Simple/there is-are/was-were; A2: Past Simple/going to-will/should; B1: Present Perfect/деловое письмо/условные; B2: смесь времён/идиомы/пассив+формальный регистр). `/course/[c]/writing` — список (переиспользует UnitList.module.css), `/course/[c]/writing/[prompt]` — практика: textarea с автосохранением черновика в localStorage, счётчик слов, чек-лист самопроверки (эфемерный, не персистится), кнопка «Показать пример ответа», «Отметить как выполнено» (переиспользует lib/progress.ts с ключом `writing-{slug}`).
- **Speaking**: НЕ потребовал нового контента — `lib/phrasebook.ts` собирает все существующие `phrase` поля из шагов заданий всех глав уровня (уже написанные полные фразы-«разговорник», 20–35 уникальных на уровень). `/course/[c]/speaking` — единая тренировочная сессия (без списка/прогресса — как ASR шумный, так и философия «без штрафов» не про персистентную оценку): Web Speech API (`lib/useSpeechRecognition.ts`, поддержка `SpeechRecognition`/`webkitSpeechRecognition`) записывает речь, `lib/speaking.ts` даёт грубую оценку по доле совпавших слов (0-100, вердикты great/close/retry). Фолбэк-сообщение для браузеров без поддержки (Safari/Firefox) — предлагает Chrome.
- **Важный паттерн, зафиксированный в этом этапе**: Next.js статически проверяет модуль на импорт React-хуков ДО вызова — если файл экспортирует и server-safe функции, и хук (useState/useEffect), а его импортирует хоть один server-компонент (например, страница-обёртка `/vocabulary/train/page.tsx`), сборка падает с «Attempted to call ... from the server» либо с ошибкой хука. Решение: держать server-safe данные/функции в одном файле БЕЗ `"use client"` и БЕЗ импорта react, а хуки — в отдельном файле с `"use client"` (`lib/vocabulary.ts` + `lib/useVocabProgress.ts`, `lib/writing.ts` — вообще без хуков). Проверять это при любом новом lib-файле, который будет использоваться и в server, и в client коде.
