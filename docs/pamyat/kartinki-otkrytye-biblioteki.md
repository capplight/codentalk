**Владелец 3 сентября 2026: «сделанные тобой картинки плохие, должна быть
какая-то общедоступная библиотека картинок и элементов для уроков, найди, и
используй».** Своё рисование прекращено.

Лицензии проверены по страницам самих библиотек, цитаты дословные —
`docs/beginner-2/kartinki-otkuda.md`.

| Библиотека | Лицензия | Для чего |
|---|---|---|
| **Twemoji** | CC-BY 4.0; сам проект пишет, что довольно упоминания «in a project README or an "About" section or footer» | основа: ~3600 значков **в одном стиле** — занятия, предметы, места, состояния |
| **Openclipart** | CC0, «there is no need to cite Openclipart» | чего нет у Twemoji |
| **Open Peeps** | CC0, «free for commercial and personal use» | люди для сцен |
| **unDraw** | коммерчески можно, авторство не нужно | большие сцены |

**Главный довод за Twemoji — единый стиль.** Своё рисование его не даст никогда:
каждая схема выходит своя.

**ДВА ЗАПРЕТА, КОТОРЫЕ ЛЕГКО НАРУШИТЬ:**

1. **unDraw пачкой качать нельзя.** Их условия прямо запрещают раздачу
   иллюстраций пачками, скачивание скриптом и «any automated processing of the
   assets for AI/ML model development». Только по одной руками.
2. **На боевом сайте картинки должны лежать у нас**, а не тянуться с чужого
   адреса. То же правило, по которому шрифты забираются во время сборки. В
   образце адрес чужой нарочно — чтобы картинки было видно сразу.

**Как брать Twemoji:** имя файла — код знака,
`https://cdn.jsdelivr.net/gh/jdecked/twemoji@15.1.0/assets/svg/1f697.svg` — 🚗.
Осторожно: часть знаков лежит БЕЗ указателя вида `fe0f` — `261d-fe0f` отдаёт 404,
а `261d` работает. Каждый код проверять запросом.

Своё рисование остаётся только для схем, которых нет ни в одной библиотеке.
