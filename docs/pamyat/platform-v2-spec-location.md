Полное ТЗ MVP платформы CodeNTalk v2 — файл `e:\My Project\codentalk.kz\docs\TZ-platform-v2.md` (версия 0.1, черновик, август 2026). Продуктовый контекст — в [[platform-v2-vision]], границы MVP — в [[platform-v2-mvp-scope]].

**Решения, впервые принятые в ТЗ (их не было в устном обсуждении):**
- **Бесплатные курсы НЕ занимают слоты** из лимита «2 курса» — иначе freemium теряет смысл. Слот освобождается 1-го числа следующего месяца, завершённый курс освобождает слот сразу.
- **Контент в MVP остаётся в репозитории** как типизированные данные, БД хранит только пользовательские записи; таблицы курсов/модулей/уроков — зеркало, наполняемое сид-скриптом. Сид-скрипт ОБЯЗАН падать, если урок с существующим прогрессом исчез из репозитория.
- **v2 разрабатывается отдельным проектом, v1 продолжает работать**; переключение домена — после того как v2 догонит v1 по объёму английского.
- Вся бизнес-логика — за HTTP API `/api/v1/*` с первого дня, ради будущей мобилки. Правила (слоты, баллы, сертификаты) живут в `lib/domain/` без зависимостей от БД и React.
- Правильные ответы тестов никогда не уходят на клиент до отправки попытки.
- Экзамен — единственное место с жёсткой блокировкой порядка (открывается после всех модулей), в остальном порядок только рекомендованный.

**Два серьёзных риска, поднятых в ТЗ и требующих решения владельца:**
1. **Stripe не поддерживает Казахстан для выплат.** Нужен выбор: Paddle/Lemon Squeezy (merchant of record), локальные провайдеры (Freedom Pay, CloudPayments KZ, Kaspi) или зарубежное юрлицо. Разработка платежей (фаза 7) заблокирована до ответа. В коде провайдер спрятан за интерфейсом `BillingProvider`, в MVP работает заглушка.
2. **Противоречие принципов:** договорённость «зацепить в первые 7 дней» конфликтует с принципом v1 «без стриков и штрафов» (см. [[codentalk-project]]). ТЗ предлагает удержание без стриков (быстрая первая победа, всегда одна следующая кнопка, веха на 3-й день, письма по содержанию а не по расписанию). Если этого мало — владельцу придётся осознанно выбирать между принципом и удержанием.

**Полезное техническое наблюдение из ТЗ:** HTML/CSS/JS выполняются прямо в браузере в песочнице `iframe` — схема «код слева, результат справа» для бесплатного курса по вебу делается без серверной инфраструктуры и бесплатно. Серверная песочница (Judge0/контейнеры) нужна только для Python, C#, C++ — её логично отложить до появления выручки.

Открытые вопросы к владельцу собраны в разделе 15 ТЗ: юрисдикция бизнеса, география аудитории, цена и валюта, пробный период, языки интерфейса, возвраты, судьба доступа после отписки, порог сдачи экзамена.
