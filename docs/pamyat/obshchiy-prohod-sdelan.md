29 августа 2026 общий проход по ступени Elementary закрыт. Разбор —
`docs/zapiska-obshchiy-prohod.md`. Отчёт `check:content` впервые чист без
единого замечания: 494 урока, 3754 задания.

Сделано: 84 мёртвые карточки разобраны, 69 запятых перед `because` сняты по
выписке из Википедии, семь одинаковых заданий разведены, все 360 карточек
ступени сличены по значениям, восемь вопросов работ модулей переписаны, четыре
урока «Слова части» написаны и озвучены.

**САМОЕ ВАЖНОЕ ДЛЯ СЛЕДУЮЩЕЙ СЕССИИ: новое содержание прохода прошло скрипты и
сборку, но НЕ методиста и НЕ редактора.** Четыре урока слов — это 121 карточка,
двенадцать примеров и двадцать заданий. По правилу проекта на сайт это идти не
может, пока круг не пройден.

**Why:** без этой пометки следующая сессия примет чистый отчёт скриптов за
готовность и выложит непроверенное — ровно та ошибка, из-за которой 20 августа
на боевом сайте висело «ужасное объяснение».

**How to apply:** первое дело следующей сессии — методист и редактор по четырём
урокам слов и по правкам прохода. Порядок: методист первым, редактору сказать
только докладывать.
