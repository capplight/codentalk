«Возвращение» — задания из пройденных модулей внутри нового урока — **сделано и работает** (20 августа 2026, коммит `7f766b5`). Раскладка видов заданий ставит его со второго модуля Elementary и дальше в каждом.

**Как применять:** полем урока, а не блоком.

```ts
vozvrat: [{ iz: "eto-bylo", zadanie: "z1-dopisat-was" }]
```

Разворачивается перед показом (`lib/content/vozvrat.ts`), встаёт в конец урока за врезкой. Данные курса хранят ссылку — её и проверяют скрипты.

**Границы, которые нельзя нарушать:**
- берём только задания уроков, НЕ вопросы проверочных работ: банк работ не показывается до сдачи попытки;
- ссылка только назад: на модуль, который ученик уже прошёл. Ссылка вперёд, на свой модуль, на блок материала и повтор в одном уроке — ошибки, их ловит `npm run check:content`.

Ждут движка ещё два вида: **текст с несколькими пропусками** (у `gap` пропуск ровно один, у Cambridge шесть в одном тексте) и **картинки** — решение владельца, половина форматов ступени A2 на них опирается. Связано: [[lesson-format-built]], [[v2-work-order]].
