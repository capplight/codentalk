# Откуда берём картинки для уроков

Заведено 3 сентября 2026. Владелец: «уроки должны иметь картинки, сделанные тобой
картинки плохие, должна быть какая-то общедоступная библиотека картинок и
элементов для уроков, найди, и используй».

Своё рисование прекращаем. Ниже — четыре открытые библиотеки, лицензии проверены
по их же страницам, цитаты дословные.

## 1. Twemoji — основа. Предметы, занятия, состояния

**Лицензия:** графика — **CC-BY 4.0**, код — MIT. Дословно со страницы проекта:
«Graphics licensed under CC-BY 4.0». Указание авторства нужно, но простое: сам
проект пишет, что «will accept a mention in a project README or an "About"
section or footer on a website». То есть одна строка в подвале сайта.

**Что это.** Около 3600 значков в одном стиле: люди по занятиям (врач, учитель,
студент, водитель), предметы, еда, места, погода, состояния. Для ступени A1 это
почти весь нужный словарь.

**Чем удобнее рисования от руки.** Один стиль на все 3600 картинок. Своё
рисование этого не даст никогда: у меня каждая схема выходит своя.

**Как брать.** Имя файла — это код знака:

```
https://cdn.jsdelivr.net/gh/jdecked/twemoji@15.1.0/assets/svg/1f697.svg   🚗 машина
https://cdn.jsdelivr.net/gh/jdecked/twemoji@15.1.0/assets/svg/1f3e0.svg   🏠 дом
https://cdn.jsdelivr.net/gh/jdecked/twemoji@15.1.0/assets/svg/1f9d1-200d-1f3eb.svg  🧑‍🏫 учитель
```

**Важно для боевого сайта:** на своём сайте эти файлы надо положить к себе, а не
тянуть с чужого адреса. Правило проекта уже действует для шрифтов — их забирают
во время сборки, а не грузят со стороны. Для образца адрес чужой, чтобы картинки
было видно сразу.

## 2. Openclipart — всё, чего нет у Twemoji

**Лицензия:** **CC0 1.0**, общественное достояние. Дословно: «there is no need to
cite Openclipart», художники отказываются от всех прав.

Решение владельца от 22 августа уже называло Openclipart источником предметов —
оно в силе, и теперь у него есть напарник.

## 3. Open Peeps — люди для сцен

**Лицензия:** **CC0**. Дословно: «Free for commercial and personal use under CC0
License», «you can copy, modify, distribute, remix… even for commercial purposes,
without asking permission». Автор — Pablo Stanley, называть его не обязательно.

Рисованные от руки люди, которых можно собирать по частям. Годится там, где нужна
сцена с человеком, а не значок.

## 4. unDraw — большие рисунки под сцену

**Лицензия:** коммерческое использование разрешено, авторство не требуется —
«You do not need to ask permission from or provide credit».

**Но два запрета, и один из них прямо про нас:** нельзя раздавать иллюстрации
пачками и нельзя «any automated processing of the assets for AI/ML model
development»; скачивание скриптом без согласия тоже запрещено. **Значит качать
unDraw пачкой нельзя** — только брать по одной руками, когда нужна большая сцена.

## Что берём для чего

| Нужно | Откуда | Указание авторства |
|---|---|---|
| предмет, занятие, еда, погода, состояние | Twemoji | строка в подвале сайта |
| чего у Twemoji нет | Openclipart | не нужно |
| человек в сцене | Open Peeps | не нужно |
| большая сцена на весь экран | unDraw, по одной руками | не нужно |

## Чего мы больше не делаем

**Не рисуем сами.** Владелец сказал прямо: «сделанные тобой картинки плохие». Своё
рисование остаётся только там, где картинки нет ни в одной библиотеке и это
схема, а не предмет, — например разбор строки по частям.
