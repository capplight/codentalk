# CodeNTalk

Платформа обучения языкам и программированию. Объяснение простым языком,
упражнения с разбором после каждого ответа, серьёзная проверка знаний и
сертификат, который можно проверить по номеру.

Английский и основы веб-разработки открыты бесплатно. Остальное — по одной
подписке, не больше двух курсов одновременно.

## Принципы, которые ограничивают разработку

1. **Никаких счётчиков дней подряд, «жизней» и наказаний.** Ошибка ведёт к
   подсказке и новой попытке.
2. **Сначала понимание, потом применение.** Правило простым языком до практики.
3. **Материалы курса — данные, а не код.** Урок добавляется без программирования.
4. **Свой темп.** Ученик никому ничего не должен успеть.

Подробнее: [docs/TZ-platform-v2.md](docs/TZ-platform-v2.md).

## Запуск

```bash
npm install
npm run dev                 разработка, http://localhost:3000
npm run build               сборка
npx next start -p 3010      проверка собранного сайта
```

Для проверок используется порт **3010**: 3000 занят другим приложением.
Освободить порт на Windows:

```powershell
Get-NetTCPConnection -LocalPort 3010 -State Listen | Stop-Process -Id $_.OwningProcess -Force
```

Нужна база данных — строки подключения в `.env.local`:

```
DATABASE_URL=   пул соединений, через него ходит сайт
DIRECT_URL=     прямое подключение, через него идут миграции
AUTH_SECRET=
```

## Команды

```bash
npm test                    правила без запуска сервера

npm run db:migrate          накатить миграции

```

## Устройство

```
app/
  api/v1/       программный интерфейс — единственный вход к правилам
  learn/        курсы, уроки, проверочные работы, экзамен
  dashboard/    личный кабинет
  certificate/  публичная проверка сертификата по номеру
courses/        учебное содержание как данные
lib/
  content/      формат урока: типы, проверка ответов, проверочные работы
  domain/       ЧИСТЫЕ правила: без базы, без React, покрыты тестами
  api/          связка правил с базой
  db/           подключение к базе
components/lesson/   страница урока и её острова
prisma/         схема и миграции
materials/      источники: описания ступеней, руководства, словники
docs/           техническое задание, программа курса, формат урока
```

**Правило слоёв.** `lib/domain/` не знает ни про базу, ни про React. Правила
живут там и проверяются тестами без запуска сервера — чтобы будущее мобильное
приложение переиспользовало их через программный интерфейс.

**Правило проверки прав.** Скрытая в интерфейсе кнопка защитой не является.
Каждый метод интерфейса заново проверяет подписку и занятое место.

**Правило ответов проверочных работ.** Правильные ответы, разборы и подсказки
не уходят в браузер до сдачи попытки.

## Как добавить урок

Учебное содержание — обычные файлы в `courses/`, программировать не нужно.

1. Открой [docs/format-uroka.md](docs/format-uroka.md) — там семь видов блоков
   материала и девять видов заданий.
2. Добавь модуль по образцу `courses/english-starter/privetstvie.ts`.
3. Впиши его в `courses/<курс>/index.ts`.
4. Проверь: `npm run check:content`.
5. Перенеси в базу: `npm run db:seed:courses`.

Содержание не принимается автором: его смотрят два проверяющих из
`.claude/agents/` — методист сверяет по источникам в `materials/`, редактор
проверяет русский язык. Порядок приёмки описан в [CLAUDE.md](CLAUDE.md).

## О первой версии

До этого существовала первая версия: статический сайт с историями-квестами и
успехами в браузере. Её учебное содержание было написано без опоры на учебники,
поэтому владелец решил его выбросить, а страницы удалить. В дереве от неё
ничего не осталось; посмотреть можно только историей коммитов, начиная с
`3f3a78e`.
