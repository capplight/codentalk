# CodeNTalk — языки и код через лёгкие квесты

Бесплатная платформа для изучения языков (а позже — программирования) через
истории-квесты. Каждая глава — маленькое приключение: задания вплетены в сюжет,
ошибки не наказываются, а наградой служит собранный разговорник.

**Принципы продукта:**

- Без стриков, сердечек и давления — ошибся, получил подсказку, пошёл дальше.
- Сюжет вместо карточек: фразы запоминаются, потому что ученик их «прожил».
- Озвучка каждой фразы (Web Speech API — бесплатно, без внешних сервисов).
- Прогресс хранится в localStorage — сайт работает без аккаунтов и бэкенда.

## Запуск

```bash
npm install
npm run dev        # разработка — http://localhost:3000
npm run build      # продакшен-сборка (все страницы статические)
npm start          # запуск собранного сайта
```

## Деплой на Vercel (бесплатно)

1. Залейте репозиторий на GitHub.
2. На [vercel.com](https://vercel.com) → **Add New Project** → выберите репозиторий.
3. Настройки менять не нужно — Vercel сам распознаёт Next.js. Нажмите **Deploy**.
4. Привяжите домен `codentalk.kz` в **Settings → Domains**.

Сайт полностью статический, так что подойдёт и любой другой хостинг
(Cloudflare Pages, Netlify).

## Как добавить новую главу

Контент отделён от кода — глава описывается данными, программировать не нужно.

1. Создайте файл `content/english-a1/chapter-3.ts` по образцу
   [chapter-2.ts](content/english-a1/chapter-2.ts).
2. Добавьте импорт и главу в массив `chapters` в [content/index.ts](content/index.ts).
3. Готово — страница главы, прогресс и финальный экран появятся автоматически.

### Типы шагов главы

| kind       | Что это                                                        |
| ---------- | -------------------------------------------------------------- |
| `story`    | Кусочек сюжета или реплика персонажа (не блокирует, идёт дальше сам) |
| `choice`   | Выбор правильной реплики/перевода из вариантов                 |
| `assemble` | Собрать фразу из перемешанных слов                             |
| `fill`     | Вписать пропущенное слово                                      |
| `listen`   | Аудирование: фраза озвучивается (текст скрыт), выбрать её смысл |
| `reading`  | Чтение: текст (записка/письмо/статья) + серия вопросов по нему |
| `listening`| Большое аудирование: озвучивается фрагмент из нескольких предложений, вопросы открываются после прослушивания |

В английском тексте `story`-шагов работает разметка `{word|перевод}` — слово
становится кликабельным с всплывающим переводом.

Поле `note` у задания — мини-объяснение (💡). Оно скрыто, пока ученик не ошибётся,
и появляется как подсказка после неправильного ответа. Пишите его так, чтобы ответ
можно было вывести из правила, а не прочитать готовым. Если `note` не задан,
движок показывает автоматическую подсказку (первое слово, число букв и т.п.).

Поле `phrase` у задания добавляет фразу в «разговорник» финального экрана.
Поле `stage` привязывает шаг к этапу маршрута (иконки прогресса сверху).

### Новый курс

Добавьте объект курса в `courses` в [content/index.ts](content/index.ts).
Курс с `comingSoon: true` показывается в каталоге как анонс без ссылки.

## Структура проекта

```
app/                    страницы (App Router)
  page.tsx              главная: лендинг + каталог курсов
  course/[course]/      страница курса (список глав + прогресс)
  course/[course]/[chapter]/   прохождение главы
components/
  quest/                движок квестов: QuestPlayer + типы заданий
  ChapterList.tsx       список глав с прогрессом из localStorage
content/                КОНТЕНТ: курсы и главы (данные, не код)
lib/
  types.ts              модель контента
  progress.ts           прогресс в localStorage
  speech.ts             озвучка (Web Speech API)
prototype-chapter1.html первый прототип (одностраничный, до Next.js)
```

## Путь изучения английского

Уровни CEFR как «сезоны» одной сквозной истории:

| Уровень | Сезон | Статус |
| ------- | ----- | ------ |
| Starter (A0) | «Сборы в дорогу» — Алматы, подготовка с Айданой | ✅ 5 глав |
| A1 | Сезон 1 «Лондон» — неделя в Лондоне с Данияром | ✅ 6 глав |
| A2 | Сезон 2 «Возвращение» — стажировка в Лондоне | ✅ 6 глав |
| B1 | Сезон 3 «Своя жизнь в Лондоне» — переезд, команда, свой проект | ✅ 6 глав |
| B2 | Сезон 4 «Финал» — конференция, переговоры, юмор, возвращение домой | ✅ 6 глав |

Каждый уровень заканчивается **экзаменом** (глава с `exam: true`): смешанное
испытание по всем навыкам уровня с оценкой по числу подсказок. Финал последней
главы курса автоматически ведёт на первый урок следующего уровня.
Путь английского завершён полностью: Starter → A1 → A2 → B1 → B2.

## Разделы уровня

Каждый уровень — учебный хаб из четырёх разделов (`/course/<slug>/...`):

| Раздел | URL | Что внутри |
| ------ | --- | ---------- |
| 🗺️ Квесты | `/quests` | Сюжетные главы + экзамен (`section` не задан) |
| 📖 Правила | `/rules` | Грамматический справочник уровня (`content/<level>/rules.ts`, тип `RulesSet`) |
| 📄 Тексты | `/texts` | Главы с `section: "text"` — чтение и аудирование с вопросами: сюжетные практики и адаптации классики из общественного достояния (Эзоп, Уайльд, О. Генри, Конан Дойл, Толстой, Чехов, Джером) |
| 🏋️ Упражнения | `/exercises` | Главы с `section: "exercise"` — тренажёры грамматики (по два на уровень) |

«Следующая глава» и прогресс считаются внутри своего раздела; мостик на
следующий уровень ведёт только сюжетная ветка (после экзамена).
